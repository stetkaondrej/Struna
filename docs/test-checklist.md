# Ruční test na iPhonu

Projdi před každým vydáním. Trvá asi 10 minut. Zaškrtni, co funguje. Co nefunguje, napiš Claudovi.

**Verze:** ______ · **Datum:** ______ · **Telefon:** iPhone 12 Pro, iOS ______

## Instalace
- [ ] V Safari otevři https://stetkaondrej.github.io/Struna/
- [ ] Sdílet → Přidat na plochu. Na ploše je ikona Struna (žlutý kruh se strunou)
- [ ] Z ikony se aplikace otevře na celou obrazovku, bez lišty Safari

## Záložky a vzhled
- [ ] Všech 5 záložek dole se přepíná (Dnes, Mapa, Cvičení, Akordy, Já)
- [ ] Ozubené kolečko vpravo nahoře otevře Nastavení, šipka vede zpět
- [ ] Nic se nepřekrývá s hodinami nahoře ani s lištou dole
- [ ] Tmavý režim iPhonu (Nastavení → Displej) změní barvy a vše je čitelné

## Cvičení a časovač
- [ ] Dnes → **Začít cvičit**. Otevře se Cvičení a čas běží
- [ ] Během cvičení displej nezhasne (počkej déle, než je nastavené automatické zamčení)
- [ ] **Pauza**: čas se zastaví. **Pokračovat**: běží dál
- [ ] Během cvičení zavři aplikaci (přejeď nahoru a odhoď ji), počkej 2 minuty, otevři ji. Časovač běží a čas je o 2 minuty vyšší
- [ ] Zamkni telefon tlačítkem, počkej minutu, odemkni. Čas sedí
- [ ] **Hotovo** po aspoň 1 minutě: oslava s XP. **Zpět na Dnes**: minuty v kroužku přibyly
- [ ] Začni a hned dej Hotovo: hláška „kratší než minuta se neukládá“

## Série, body a cíl
- [ ] Po cvičení aspoň 5 minut: na Dnes „🔥 1 den v řadě“ a dnešní kolečko je zelené s fajfkou
- [ ] Úroveň 1 a XP odpovídají minutám (např. 7 minut = 7 / 100 XP)
- [ ] Po splnění denního cíle: „Dnešní cíl splněn!“ a +20 XP
- [ ] Nastavení → Denní cíl 10 min. Na Dnes je „z 10 min“
- [ ] Zítra a pozítří: série roste (zkontroluj průběžně v dalších dnech)

## Denní mise (krok 2)
- [ ] Na Dnes nahoře „Dnešní mise“ se 3 úkoly
- [ ] Klepnutí na úkol ho odškrtne a přičte +10 XP. Další klepnutí odškrtnutí vrátí
- [ ] Všechny 3 úkoly: hláška „Mise splněna! +10 XP navíc“
- [ ] Zavři a otevři aplikaci: odškrtnuté úkoly zůstaly a mise je stejná

## Akordy (krok 2)
- [ ] Záložka Akordy: 7 akordů (Em, Am, E, A, D, G, C)
- [ ] Klepni na akord: velký prstoklad s čísly prstů, tip, přepínač „Učím se“, hvězdičky
- [ ] Nastav hvězdičky a „Učím se“, vrať se zpět. Na kartě akordu je vidět změna
- [ ] Zítra: druhý úkol mise je akord „Učím se“ s nejméně hvězdičkami

## Domácí úkol a deník (krok 2)
- [ ] Já → Přidat úkol po lekci → napiš úkol → Uložit. Úkol je vidět v Já
- [ ] Pokud dnešní rozcvička ještě není odškrtnutá, úkol se objeví v dnešní misi. Jinak zítra
- [ ] Já → Úkol splněn. Úkol se přesune do „Starší úkoly“
- [ ] Po cvičení na oslavě → Zapsat do deníku → vyplň a vyber smajlík → Uložit. „+5 XP“
- [ ] Zápis je v Já → Deník. Druhý zápis téhož dne už XP nedá
- [ ] Já → Moje čísla: minuty, dny, nejdelší série, úroveň

## Ukládání dat
- [ ] Zavři aplikaci a otevři znovu. Minuty, série i XP zůstaly
- [ ] Restartuj telefon a otevři Strunu. Vše zůstalo

## Offline
- [ ] Zapni režim letadlo
- [ ] Zavři a otevři Strunu. Otevře se a jde odcvičit krátké cvičení
- [ ] Vypni režim letadlo

## Záloha a obnova
- [ ] Nastavení → Zálohovat → Uložit do Souborů (nebo Google Drive). Objeví se „Záloha je hotová.“
- [ ] Odcvičit další krátké cvičení (minuty na Dnes přibydou)
- [ ] Nastavení → Obnovit ze zálohy → vyber soubor `struna-zaloha-…json` → Obnovit
- [ ] Minuty na Dnes jsou zpět na stavu ze zálohy
- [ ] Zkus obnovit jiný soubor (např. fotku). Objeví se srozumitelná chyba, data zůstanou

## Jazyk
- [ ] Nastavení → English. Všechny texty jsou anglicky
- [ ] Zavři a otevři aplikaci. Angličtina zůstala
- [ ] Přepni zpět na češtinu
